# Vocabulary sources and review

## Current checkpoint

The retained base vocabulary had **6,005 distinct written words** in 6,092 entries. The current Stage 2 vocabulary has **11,295 distinct entry spellings**, **14,157 surfaces including inflections**, and **16,321 entries**. These counts describe dictionary breadth, not language coverage. It preserves all 165 entries from the [earlier seed](../data/candidates/seed-165.json). The [import record](../data/candidates/draft-5000.json) adds 2,500 count nouns, 2,336 adjectives, 1,000 sourced given names, 36 present transitive verbs, 27 present intransitive verbs, and authored grammar words and pronouns. Multiple entries may share a written word because they have different grammatical roles. The name pool now has 1,001 entries including the preserved seed's `washington`; `tom` and `bobby` are included. The owner approved the earlier 5,000-word base; the new name and verb coverage awaits review. The matching `data/semantics/1.0.0.json` is a pre-release archive for the intended first publication, not an earlier published version.

Numbers are generated by the grammar rather than listed as words. Present-tense verbs have explicit base and third-person forms and separate transitive/intransitive roles. The name and verb pools are much broader than the seed, but a word's role can still sound awkward in a particular decoy; review actual readings as well as individual entries.

## Source and attribution

The 165-entry seed came from [English Wiktionary data through Kaikki/Wiktextract](https://kaikki.org/dictionary/English/). [Its manifest](../tools/vocabulary/source-manifest.json) lists the source page URLs and hashes; [its source slice](../tools/vocabulary/source-slice.jsonl) contains compact grammatical evidence. Wiktionary contributors offer the source under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) or GFDL; this project uses the CC BY-SA 4.0 path. The data was modified by selecting terms, assigning roles and IDs, choosing forms, and excluding unsupported uses. See [Wiktionary copyright information](https://en.wiktionary.org/wiki/Wiktionary:Copyrights).

The additional entries use [Open English WordNet 2025](https://en-word.net/downloads) for word senses and [wordfreq 3.1.1](https://github.com/rspeer/wordfreq) for frequency ranking. Open English WordNet is [CC BY 4.0 with its stated underlying Princeton WordNet terms](https://github.com/globalwordnet/english-wordnet/blob/main/LICENSE.md); wordfreq is [Apache 2.0](https://github.com/rspeer/wordfreq/blob/master/LICENSE.txt). The committed [large-source manifest](../tools/vocabulary/large-source-manifest.json) pins both WordNet archives, the frequency list, and the seed by SHA-256. This candidate modifies those inputs by selecting words, lowercasing forms, assigning PakuPaku roles and IDs, and generating regular plurals. The browser downloads only the resulting static JSON.

The name list comes from [Social Security Administration national birth-name counts](https://www.ssa.gov/oact/babynames/limits.html), using annual records for 1880–2020 in a [pinned mirror of SSA's archive](https://github.com/hackerb9/ssa-baby-names/tree/0b1a1316457d55447d1a1f7bfe57ee15e53cc2f0/raw-data). The selector sums counts across years and sexes, keeps single lowercase ASCII names, excludes placeholder names, and takes the 1,000 highest totals. [The selected list](../tools/vocabulary/ssa-top-1000.txt) and archive hashes are pinned in the manifest. This is a specific historic U.S. frequency measure, not a universal or current-world ranking. The present-tense verb list and forms are authored project grammar data; they were not automatically classified from WordNet.

## Selection rules and limits

The builder starts with the exact seed. It takes frequent WordNet nouns from concrete/person/place/event categories when a definition begins with an indefinite article, excludes known irregular or mass-noun cases, and supplies a regular plural. It excludes noun lemmas that WordNet also marks as verbs, adjectives, or adverbs. It then fills the earlier 5,013-word base with frequent attributive adjectives, and appends the authored grammar roles and selected names. These are conservative filters, not a proof that all selected words are natural in every generated context. The exact selection and exclusions are in [the builder](../tools/vocabulary/build_large.py) and manifest.

The 165-entry seed was produced by `python3 tools/vocabulary/import_source.py`; its [original review report](../data/candidates/seed-165-report.json) retains held or excluded proposals. The larger build uses the pinned seed rather than rerunning that importer, which preserves its IDs exactly.

## Rebuild and verify

From the repository root, using Python 3.10 or newer, run `python3 tools/vocabulary/build_large.py`. The first run downloads the pinned WordNet archives into `~/.cache/pakupaku-vocabulary` and verifies their hashes. Subsequent builds can run with `--offline`. The wordfreq ranking and selected name list are committed, so rebuilding the vocabulary does not need a runtime service. To regenerate the name list from the pinned SSA mirror, download its `raw-data/names.zip`, verify the archive hash in the manifest, then run `python3 tools/vocabulary/build_names.py names.zip`. Review changes to the manifest, inputs, current vocabulary, and report together.

The current JSON size and phone performance need a fresh measurement after the name and verb additions. Earlier timing figures no longer describe this vocabulary.

## Try the current vocabulary

Serve the repository with `python3 -m http.server 8080 --bind 127.0.0.1` and open `http://127.0.0.1:8080/codec-demo.html`. Try `hello`, `i love you`, `tom loves bobby`, `the cats love you`, `good morning, sally`, and `sally slept. hello`. Create a link with a key of at least three characters, then read it with the same key and several other keys. An old `?vocab=candidate` query is ignored; no version has been publicly released.

## Stage 2 grammatical extension

`python3 tools/vocabulary/extend_stage2.py` rebuilds current `1.0.0` vocabulary and its matching archive from the retained `data/candidates/draft-5000.json` base plus `tools/vocabulary/stage2-lexicon.json`. The extension contains project-authored, sense-specific complement-frame classifications and explicit inflections, common count nouns, predicative adjectives and subject-pronoun agreement. It does not guess grammatical roles for unknown input.

Article pools use the first pronunciation in CMUdict, pinned to commit `74790861f652b15e4ac49015a90074ad62a27690`; source and license SHA-256 values are recorded in the extension specification and verified during rebuild. Copyright © 1993–2015 Carnegie Mellon University; retain the [full license and disclaimer](../tools/vocabulary/cmudict-LICENSE) with redistribution. Unknown pronunciations remain unclassified for article selection. This pronunciation choice does not establish coverage of every regional variant.

The runtime schema no longer imposes the prototype 10,000-entry or ASCII-only restrictions. This permits explicitly sourced Unicode lexical entries; unknown names remain failures. Existing imported noun forms and adjective senses still need an expanded quality audit. Adding a reviewed frame does not certify every sense of its lemma.

## Development dependency extension

`npm run vocabulary:stage2` first rebuilds the development-only local dependency
grammar and lexical classes, then rebuilds the static vocabulary and matching
archive. [Design, provenance and limitations](coverage/dependency-grammar.md)
record the EWT/GUM attribution and licenses. These generated classes supplement
the reviewed vocabulary; they are not assertions that every source annotation
or lexical sense is correct. Unknown or narrow senses have explicit singleton
classes, whose content disclosure is measured in the Stage 2 layout audit.

## Geography extension

The [geographic catalog](geography-vocabulary.md) adds all 50 states, five
city/place selections per state including every capital, and 200 country/territory
entities with common spelling variants. `build_geography.py` verifies a pinned
country-source hash and combines it with the authored state/city table. The
source data and ODbL license are retained. The inventory is broad coverage,
not a measured discussion-frequency ranking.

Geographic entries may contain multiple words or an abbreviated saint name.
Each is a single keyed semantic choice. Runtime lexical productions recognize
its complete token sequence and expose valid prefixes to the composer; they
do not allow arbitrary combinations of name components. Article-requiring
bare names are separately available as standalone labels.
